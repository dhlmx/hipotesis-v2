 Planteamiento

El algoritmo K-Nearest Neighbor se utiliza para predecir o clasificar un dato determinado en base a un conjunto de datos ya clasificados. Por lo tanto, se trata de un método de clasificación o predicción de datos en el aprendizaje supervisado.


El funcionamiento del algoritmo K-Nearest Neighbor consiste en encontrar un número "k" de vecinos, los más cercanos, con respecto a un conjunto de datos aún no etiquetado o clasificado. Por consiguiente, se le asignará la etiqueta o clasificación que sea más común entre esos vecinos.

 Datos

Los datos fueron obtenidos de nuestras fuente de estudio y referencia. Se trata de una colección de casi quinientos registros de personas, con datos de peso, altura y género.


El género es la variable de salida, mientras que el peso y la altura son las variables de entrada. El objetivo es predecir el género de una persona en base a su peso y altura.
