 Planteamiento

El algoritmo Support Vector Machine, SVM, es un clasificador que a través de cálculos matemáticos avanzados y complejos intenta crear líneas que separen geométricamente cada clase identificada de las demás, dentro de un conjunto de datos determinado. El algoritmo utiliza un margen de separación entre las clases separadas por líneas, ese parámetro se llama margen, identificado por w. Existen otros parámetros adicionales de configuración.


Por su método geométrico de clasificación, es un método algo limitado, pero muy útil para casos binarios, donde las mediciones pueden distinguirse claramente desde un punto de vista geométrico.


Al tener un entrenamiento con datos previamente etiquetados, se trata de un método de clasificación o predicción de datos en el aprendizaje supervisado.


Existen diferentes variantes del SVM, entre los que destacan el Support Vector Machine con kernel lineal, Support Vector Machine con kernel polinomial, Support Vector Machine con kernel radial y Support Vector Machine con kernel sigmoidal, entre otros.

 Datos

Los datos de entrada fueron obtenidos de nuestra fuente de estudio y referencia. En este caso se trata de una serie de mediciones de sepáculos y pétalos de la flor de iris, realizados alrededor de 1936 por el botánico Edgar Anderson y el biólogo y estadístico Ronald Fisher.


En total, se trata de 600 mediciones, 150 por cada dimensión o característica medida: longitud y ancho de los sepáculos y pétalos de la flor de iris. A su vez, cada conjunto de 150 mediciones se corresponden con las tres especis de iris existentes: Setosa, Versicolor y Virginica.


Por consiguiente, cada especie de iris se encuentra representada por 50 mediciones en centímedtros de la longitud y el ancho de sus sepáculos y pétalos.


Hemos definido cada dimensión, característica o "feature" de la siguiente manera: 1D, longitud de sepáculo; 2D, ancho de sepáculo; 3D, longitud de pétalo; y 4D, ancho de pétalo.


El objetivo es predecir la especie de iris a partir de las mediciones de la longitud y ancho de sus sepáculos y pétalos.

 Solución

La aplicación realizará la predicción de una muestra aleatoria de quince mediciones tomadas de los datos de la flor de iris. El resto de los datos serán utilizados para el entrenamiento del algoritmo.


El entrenamiento del modelo se realiza suministrando las 4 dimensiones mencionadas en el planteamiento del problema (1D, 2D, 3D y 4D) junto a la etiqueta de la especie correspondiente.
