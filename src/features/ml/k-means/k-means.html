 Problema

El algoritmo K-Means suele utilizarse para agrupar datos en torno a un centroide de referencia. Por lo tanto, se trata de un método de agrupamiento de datos (clustering) en el aprendizaje no supervisado.

 Datos

La aplicación provee un generador de datos aleatorios que nos permite crear un conjunto de puntos (coordenadas irrepetibles de enteros positivos) para el entrenamiento. Recomendamos utilizar unos 40 puntos para hacer más evidentes los resultados, desde un punto de vista gráfico o visual.

Se aceptan de 2 a 3 dimensiones, cada una determinada por un rango.
